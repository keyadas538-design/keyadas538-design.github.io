# Picto-Inspired BCA Portfolio

A clean, corporate personal portfolio built with:
- HTML5
- CSS3
- Vanilla JavaScript
- Work Sans

## Folder structure

portfolio/
├── index.html
├── css/style.css
├── js/script.js
├── images/

Replace:
- "Your Name"
